### 取舍与两个非阻断待改

独立代码审查无 Critical/Important，以下 Minor 保留而不扩展本轮性能修复范围：

1. 全局中文 404 没有导入新 Han 分片样式，中文错误提示会使用系统中文字体；正常官网中英文页面不受影响。需要后续补全入口字体引用。
2. 路由清单生成器针对当前工具生成的 JSON 字面量。若将来把目标数组改成函数调用等非字面量，并在后面放其他数组，扫描器可能选错声明。当前 104+104 路由库存测试通过，但不能声称对任意未来格式“失败关闭”；修改内容生成格式必须同时改进生成器并跑库存测试。

实施判断：TypeScript 7 原生包不提供此前的 JS AST API，改用不执行内容的字面量扫描器；避免新增生产依赖，代价是上述未来格式兼容边界。代码审查不替代生产操作和测速，后者由隔离验证、备份/健康检查和三轮实测提供证据；未更改的 CMS 只做现有回归，不声称完成新一轮全面安全审计。

## 实施决策、代价与未操作项

1. 选择公开静态文件 24 小时非 immutable 缓存，而非新增 CDN。代价：同名替换静态文件可能继续显示旧版一天，后续应更换文件名或 URL 版本。运营后台的上传图片使用唯一地址，不受同名缓存影响。
2. 缓存规则由构建时真实文件列表生成。代价：新增服务器静态素材需要随正常发布重建；发布目录内的这些文件不得单独移除。
3. 缓存规则按大小写匹配，防止错误大小写的 404 被缓存。已验证现有中英文、产品详情及尾斜杠跳转。当前没有自定义大小写别名；如果将来添加这类别名，需要显式定义并验证。
4. 既有 CMS/域名代码不在本次增量审查范围，依赖此前审查及本次回归。生产切换、备份、数据不覆盖和远端分支分别依据实际执行证据。网络测量不代表全网 DNS 已更新，本次不修改域名或电脑 DNS。
