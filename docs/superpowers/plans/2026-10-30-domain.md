# apowertech.net Domain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 沿用用户要求的直接执行；复用现有隔离worktree，不另建项目。

**Goal:** 为已部署官网准备正式域名接入，DNS可验证后完成HTTPS与后台来源切换。
**Architecture:** 现有Nginx/Certbot，两阶段配置，不修改运营数据或DNS。
**Tech Stack:** Nginx1.26、Certbot5.9、现有Next16/Node24。
**Spec:** docs/superpowers/specs/2026-10-30-domain-design.md

## Global Constraints

- 服务器177.5.75.237，主域apowertech.net，www跳转主域；现有IP HTTPS和GitHub测试站保留。
- 未通过公网DNS校验不得请求生产证书、启用不存在的证书路径或切换后台来源。
- 不修改DNS、不创建轮询任务、不提交凭据；reload前nginx -t，保留可恢复配置备份。

## Review Focus

- 尚未签发证书时，域名HTTP不能暴露明文CMS或损坏现有IP HTTPS。
- ACME例外须在两个域名上可读，其他路径固定目标重定向，不能信任任意Host拼接。
- 未知Host拒绝，API仍需登录、Origin仍校验。
- www、根域、AAAA/CAA等不一致时不得误报证书已完成。
- DNS切换与服务器准备分离，用户必须知道尚未完成哪些步骤。
