# APOWER 官网与运营后台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 用户已要求直接采用推荐方案，本会话直接执行，不再等待问答。

**Goal:** 安全地部署保留现有外观的动态官网和运营后台。

**Architecture:** 原静态 Next.js 入口继续服务 GitHub Pages；runtime/ 动态 Next.js 入口共享组件、读取 SQLite。数据库、图片、备份独立于发布目录，Nginx HTTPS 代理非 root 服务。

**Tech Stack:** Next.js 16.3.5 / React 19.3、Node 24、node:sqlite、sharp 0.35.4、Nginx、systemd。

**Spec:** docs/superpowers/specs/2026-10-30-admin-design.md

## Global Constraints

- 保留现有官网样式、手机布局、中英文和已有资料；不改变静态测试站部署。
- 图片 8MiB；登录 session 12 小时；初始账号必须改密；备份最近 7 天。
- 不复用 root 密码，不把密码/数据库/上传文件提交到 Git。

## Review Focus

- 删除或下架种子内容后，不得由原静态数据回退复活。
- 并发编辑有冲突提示，恶意图片和目录穿越不能写任意位置。
- 角色变更/禁用/改密后旧 cookie 不能继续写入。
- HTTPS、原始 Host/Origin 与代理头不能绕过后台防护。
- 发布目录更换或进程重启不能覆盖数据库、图片和账号。
