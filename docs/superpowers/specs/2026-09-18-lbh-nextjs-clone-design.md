# LBH Appliances 双语 Next.js 复刻设计

## 目标

在当前仓库中使用 Next.js App Router、TypeScript 和响应式 CSS，完整复刻 `https://lbhappliances.com/en` 及其中文站。交付物包含全部公开页面、原站公开内容与素材、桌面和移动端布局，以及与原站一致的前端交互。询盘相关流程保留完整前端体验，真实邮件发送能力留作后续接入。

## 范围

目标站点地图当前包含 102 条记录，其中核心内容包括：

- 中英文首页；
- 5 个产品分类、产品总览和 24 个产品详情；
- 公司介绍、领导团队、里程碑、工厂参观、认证证书、可持续发展和产品实验室；
- 独家销售、代工服务、品质管理、设计研发、订单管理、产品制造和售后服务；
- Blog、FAQ、新闻列表与 34 篇新闻或问答详情；
- 联系页面、产品目录与公开下载入口。

站点地图中的重复地址只生成一份内容。中英文内容按语言分别保存，但复用同一套页面结构和组件。

## 信息架构与路由

- `/en` 和 `/cn` 分别作为英文与中文入口。
- 内容页继续使用原站可识别的路径名称，例如 `/en/Company_Introduction` 与 `/cn/Company_Introduction`。
- 产品分类、产品详情、新闻列表与新闻详情使用动态路由配合静态参数生成。
- 原站未带语言前缀的历史链接通过重定向或兼容路由进入对应英文页面。
- 语言切换器优先跳转到当前页面的另一语言版本；若目标语言没有对应内容，则跳转到该语言首页。
- 未知的产品、文章或页面显示对应语言的 404 页面。

## 页面与组件

全站共用以下基础组件：

- 桌面顶栏、下拉导航和移动端抽屉导航；
- 语言切换器；
- 页脚、悬浮联系入口和返回顶部按钮；
- 全宽横幅、内容区块、数字指标、产品卡片、新闻卡片和行动按钮；
- 询盘弹窗及表单；
- 视频弹窗、轮播、标签页、FAQ 折叠面板、图片画廊与灯箱。

页面按用途复用模板：

- 首页模板负责首屏轮播、制造实力、产品推荐、品牌介绍、认证、使命与联系入口；
- 产品列表模板负责分类导航、产品网格、定制能力、制造流程与认证内容；
- 产品详情模板负责图片画廊、规格参数、功能与配件标签页及询盘入口；
- 企业与服务内容模板负责横幅、图文区块、时间线、统计数据及行动按钮；
- 内容模板负责 Blog、FAQ、新闻列表和详情；
- 联系模板负责联系方式、地图或地址区块和询盘表单。

## 内容与数据模型

导航、页面文案、产品、分类、新闻、FAQ 和联系信息以本地 TypeScript 或 JSON 数据保存。每条可路由内容包含稳定标识、原站路径、语言、标题、SEO 字段、正文区块和媒体引用。

产品数据包含型号、分类、参数、主图、画廊、功能、可选配件和询盘标题。新闻数据包含发布日期、作者、正文区块和媒体。页面区块使用有限且明确的类型，避免将抓取到的任意 HTML 直接注入应用。

原站公开图片、图标、视频封面、文档和必要字体保存到 `public` 下的分类目录。应用运行时不依赖原站 CDN。外部嵌入视频在原站使用第三方播放器时保留等价播放体验，并为封面和失败状态提供稳定布局。

## 视觉设计

视觉目标是复刻而非重新设计：

- 保留黑色顶部导航、橙色品牌强调、暖米色产品场景、白色内容区和全宽影像；
- 首页首屏保持左侧橙色标题与卖点、右侧产品组合图和轮播编号；
- 对齐原站字体层级、段落宽度、区块高度、留白、卡片比例、按钮和悬停状态；
- 保留轮播、滚动出现、数字增长和菜单过渡的节奏，同时尊重 `prefers-reduced-motion`；
- 以 1440px 桌面宽度和 390px 移动宽度作为主要截图比对基准；
- 移动端使用抽屉导航，保持内容顺序、点击目标大小与媒体比例，不出现横向溢出。

## 交互与状态

- 桌面导航支持悬停与键盘操作；移动导航支持打开、关闭、子菜单展开和焦点管理。
- 轮播支持按钮、指示器、触摸滑动和自动播放；用户交互后不会产生突兀跳转。
- 产品画廊支持缩略图切换和大图查看；详情标签页支持键盘访问。
- FAQ、视频弹窗、返回顶部和语言切换行为与原站语义一致。
- 询盘表单包含必填校验、格式校验、提交中、成功和失败状态。首阶段调用本地模拟提交逻辑；接口边界固定为 `/api/inquiry`，后续接邮箱时不改动页面组件。
- 媒体失败时保留原有占位尺寸并显示低干扰回退，避免页面跳动。

## 技术架构

- Next.js App Router 与 TypeScript；
- 服务端组件用于页面和内容渲染，客户端组件仅承载交互；
- 可静态生成的页面在构建期生成，提升加载速度和可抓取性；
- 全站样式使用统一设计变量与分区样式，避免为每个页面复制 CSS；
- 元数据按语言和内容生成，包括标题、描述、规范链接与语言替代链接；
- 真实邮箱、数据库、登录和内容管理后台不在本阶段范围内。

## 验证与验收

完成标准如下：

1. Next.js 生产构建成功，无阻断错误。
2. 站点地图中的全部唯一公开页面都有对应中英文路由或明确的语言回退，内部链接无 404。
3. 首页、产品列表、至少两种产品详情、公司介绍、服务内容、新闻详情和联系页通过桌面与移动视口检查。
4. 导航、语言切换、轮播、标签页、画廊、FAQ、视频弹窗、返回顶部和询盘表单状态可正常操作。
5. 1440px 与 390px 下不出现非设计性的横向滚动、内容遮挡或文字重叠。
6. 关键页面与原站截图对比，布局、颜色、字体层级、媒体比例和主要间距达到肉眼难以区分的还原目标。
7. 所有必要公开素材从本项目加载；不存在依赖原站页面 HTML 或原站业务接口才能显示的内容。

## 交付

交付完整 Next.js 源码、结构化双语内容、本地化素材、可运行的生产构建和私有预览地址。真实邮件发送在后续提供邮箱服务配置后接入既有 `/api/inquiry` 边界。

## 非目标

- 不复制原站的管理后台、数据库、访问统计或私有接口；
- 不在本阶段发送真实邮件；
- 不新增原站没有的电商结算、账户、搜索或内容管理功能；
- 不对品牌视觉和内容进行重新设计。
