# 昂玖熙 B2B 官网

面向直播团队、南油二批/女装档口与实体门店的女装牛仔品牌及供应链网站。

## 本地查看

1. 在项目根目录运行 `npm run build`。
2. 运行 `npm run dev`。
3. 浏览器打开 `http://127.0.0.1:4173/`。

网站不依赖第三方前端框架或在线字体，构建结果输出到 `out/`。正式发布时请设置 `SITE_URL` 为实际域名后重新运行构建，以便 canonical、分享链接、站点地图和 robots 文件使用正式网址。

## 页面

- 首页
- 当季选款方向
- 直播团队合作
- 南油二批与女装档口合作
- 广州展厅与供应链
- 牛仔知识库（8 个独立问答页面）
- 联系与预约

## 内容维护原则

- 款号、价格、库存、起订与交期按具体款式和订单确认，不在官网编造统一数字。
- 未核实的排名、经营数据、认证、客户名称和极限承诺不得写入公开页面。
- 飞书知识库与视频素材库接入属于下一阶段；接入前应先更换曾在聊天中出现过的机器人密钥。
